复核日期：2026-09-20。范围为本地制图工具的静态蓝图预览、右侧详情及 PNG 导出。依据为用户提供的游戏截图、BlueprintPreview / BlueprintContent / BlueprintIcon / ItemIcon Lua、原始 prefab 的图片、位置与颜色数据。

| 显示层 | 当前实现与检查 |
| --- | --- |
| 建筑轮廓、底纹、中央设备符号 | 112 个建筑表条目，四向原图合成，中央符号保持正向；特殊底纹缺口见下方 |
| 物品、气体、稀有度圆环 | 864 条可搜索记录，835 张徽标；普通设备、仓库口、物品准入口、管道准入口均可标注 |

| 传送带、管道、物流节点 | 原始直线、转弯、箭头图案；8 类物流节点；端口处按设备边界衔接 |
| 设备接口 | 物品/管道、入口/出口与旋转；支持独立端口层的设备可以逐口隐藏；16 组四向图与独立 Pillow 合成结果比对 |
| 地下管道 | 配对/未配对提示、普通连接框与激活框；原始蓝色渐隐光带；两层收缩轮廓按原始动画在 0.5 秒取静态画面 |
| 更换图标提示 | 编辑器可显示；完整预览默认隐藏，可手动开启 |
| 右侧封面与详情 | 原始封面底纸、封面物品、名称、名称括号、尺寸、创作者 ID、标签、空标签外框、描述 |

| 取景与图片导出 | 滚轮缩放、拖动取景、滚动位置提示；可选择一对暗管连接随 PNG 导出；预览与导出使用同一绘制函数 |

| 字体 | 原始 HarmonyOS Sans SC 可变字体内嵌于 HTML；界面和 Canvas 统一使用，首次导出也等待字体加载后测量文字 |

状态、环境条和接口均为手动显示设置，不执行账号解锁、活动时间、生产配方、物品准入规则或环境覆盖计算。节点可选字段 `itemStatus` 为 `normal` / `locked` / `limited` / `expired`，`itemStatusColor` 为 `#RRGGBB`。状态附着于物品徽标，恢复设备符号后不显示；限时颜色只改变有效状态的背景标签。

## 尚存的素材缺口

- 29 条物品图标：3 条未配置且无同名原图，26 条配置的图名在之前扫描的当前安装资源中未找到。保留可检索记录和原因，导入时保留 ID。明细与追查证据在 `missing-icons.md` 和 `data/icon_audit.json`。
- 20 个装饰、土壤或特殊设备条目缺少大号底纹：保留中央设备符号，省略缺失底纹。完整条目列表在构建报告 `reports/display_coverage.json` 的 `knownAssetGaps.buildingWatermarks`。
- 边缘渐隐、标签外框、名称括号、图卡/数字阴影和滚动条装饰仍有 Canvas 近似绘制。当前结果仍不宣称与游戏逐像素一致；没有原始布局数据时，也不把示例图片等同于截图中的完整产线。

UID、网络延迟、手柄提示、鼠标悬停提示及游戏内实时状态不属于当前静态导出内容。右侧自动清单使用放入画布的设备，不推算游戏库存。

## 仍未复刻的效果与已明确的取舍

- 原版悬浮名称/稀有度/暗管状态提示框尚未复刻，编辑器当前已有原始悬停轮廓。
- 暗管蓝色连接光带已接入；其中 `GlowToRight` 的 shader 扫光动画没有复刻。激活框的两层脉冲采用原始动画 0.5 秒的静态快照，连续导出保持一致。
- 原版右侧图卡选中、闪光动画没有复刻；库存不足、科技、解锁和活动过期警告面板依赖游戏状态，当前不显示。手动物品状态角标不自动触发这些警告。
- 游戏图标/封面选择弹窗由本工具的 HTML 搜索界面代替。

逐层清单在 `reports/effect-layer-audit.json`，覆盖当前解出的全部 85 个 BlueprintPreview 图片组件，并为每项记录原图接入、静态动画、编辑器专用、近似实现或未实现原因。未遇到的游戏界面和 shader 效果不据此宣称全部还原。

`presentation.connectionPair` 保存要展示的暗管配对 ID。在「蓝图预览 → 暗管连接示意」选择后，完整 PNG 和画布 PNG 都可保留该连接；删除对应端点后自动停止绘制，仍保留原字段以便撤销恢复。

## 可重复验证

`python scripts/verify_inputs.py` 校验独立项目的素材与配置输入；构建后执行 `pnpm test`，使用独立浏览器上下文验证编辑、保存、搜索、旋转、接口、详情、字体加载和 PNG 导出。`pnpm smoke` 另验证从空白画布到下载、重新导入的完整 UI 流程。状态角标对照图片输出到 `reports/test-artifacts/item_status_layers.png`。本文提到的 `reports/` 内容均由构建或测试生成，不随源码仓库提交。

完整原始字体与许可保留在 `assets/fonts/`。内嵌字体与原始 TTF 按 SHA-256 比对，未做裁剪或格式转换；网页底栏的「字体许可」可查看原文。
